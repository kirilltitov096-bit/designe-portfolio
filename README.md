# Портфолио kirchatov

Адаптивное портфолио с кабинетoм `/admin`, изображениями PNG в R2 и данными D1.

## Управление
Войдите в кабинет через аккаунт ChatGPT владельца. Доступ разрешён только email из серверной настройки `ADMIN_EMAIL`. Добавьте проект, загрузите PNG (до 30 файлов, каждый до 30 МБ), укажите название, категорию, описание и порядок. Первое изображение — обложка. Галочка публикации позволяет сохранять черновики.

В кабинете также доступны заявки, модерация отзывов, изменение имени, главного заголовка, описания и Telegram. Кнопка связи ведёт на `@kirchatov`. Заявки сохраняются в кабинете. Бот не подключён по решению владельца.

## Проверка
- TypeScript: `node node_modules/typescript/bin/tsc --noEmit`
- Локальные миграции: инструкции в документации стартера.
- `scripts/integration-test.mjs` проверяет локальные API на 127.0.0.1:5173 с имитацией владельца `seedy@sites.test` (ADMIN_EMAIL в игнорируемом .dev.vars).
- Тесты создают только локальные записи и изображения. Локальная база не публикуется.

## Серверные настройки
ADMIN_EMAIL задаётся в настройках среды Sites. Не помещайте его в клиентский код.
Необязательные TELEGRAM_BOT_TOKEN и TELEGRAM_CHAT_ID включают автоматические уведомления о новых заявках. Токен помечается секретным в Sites; не храните его в репозитории.

## Хранение
D1: проекты, отзывы, заявки, настройки. R2: PNG. Миграции находятся в drizzle/. Данные сохраняются между обновлениями сайта.

Начальная коллекция: 4 проекта и 7 PNG. Данные начальной коллекции находятся в app/collection.ts. Первое редактирование владельцем переносит коллекцию в D1; последующие изменения и удаления сохраняются в базе. Оригиналы в public/works/, экранные WebP-превью рядом.

## Вступление и логотип
Вступительная анимация из хромированных орбит в монограмму КТ занимает около 2,8 секунды и проигрывается один раз за сеанс вкладки (ключ kt-orbit-intro-v3). Прокрутка не управляет знаком. При уменьшении движения сразу показывается готовый логотип.

Вектор: public/brand/kt-monogram.svg. Геометрия и траектория преобразования: app/logo-geometry.mjs. Экспорт: node scripts/export-logo.mjs.

Кнопки используют прозрачную линзу, блики по краю и SVG-карту преломления фона. Если браузер не поддерживает фильтр, остаётся вариант с размытием. Текст кнопок не искажается.

## GitHub

В репозитории находятся исходники сайта, оригинальные PNG, превью и логотип SVG. Демо для просмотра находится в docs/index.html: его можно скачать и открыть в браузере. В демоверсии формы не отправляют заявки и отзывы. Полноценному сайту для кабинета, хранения работ и заявок нужны сервер Cloudflare Workers, база D1 и хранилище R2. Публикация исходников на GitHub сама по себе не включает хостинг.
